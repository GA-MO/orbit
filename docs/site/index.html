01 — Orbit คืออะไร

ไม่ใช่แอปแชทที่คุยกับ AI แต่คือรีโมทของเครื่องคุณเอง

สิ่งที่เห็นบนมือถือคือ terminal ตัวเดียวกับที่รันอยู่บน Mac — ANSI สี, TUI, prompt ที่ต้องกดตอบ, Ctrl+C, scrollback ครบ ไม่มีการแปลงเป็นข้อความสวย ๆ ระหว่างทาง

01

MacBook คือ source of truth

ไฟล์ กิต เครื่องมือ และ agent ทั้งหมดอยู่บนเครื่องคุณ Orbit ไม่ซิงก์โค้ดขึ้นที่ไหน และไม่มีบัญชีให้สมัคร — single-user, local-first

02

Session ไม่ตายเมื่อจอดับ

PTY อยู่ฝั่ง Mac มือถือเป็นแค่จอ ปิดเบราว์เซอร์ สลับแอป เน็ตหลุด กลับมาแล้วงานยังเดินอยู่ พร้อมประวัติที่เล่นย้อนให้ครบ

03

มือถือเห็น ก็สั่งได้

พิมพ์ พูด แนบรูป ดูดิฟฟ์ เปิดแอปที่รันอยู่จริง — จบในจอเดียว โดยไม่ต้องเดินไปเปิดฝาโน้ตบุ๊ก

เส้นแบ่งที่ชัดเจน: Orbit ไม่ได้แทน agent และไม่ได้เขียนโค้ดเอง — มันคือชั้นที่ทำให้ agent ซึ่งออกแบบมาสำหรับจอ 27 นิ้ว ใช้งานได้จริงบนจอ 6 นิ้วในมือคุณ
02 — เส้นทางของหนึ่งคีย์สโตรก

จากนิ้วคุณถึง zsh ผ่านห้าชั้น

ไม่มีคลาวด์อยู่ในเส้นนี้ ตัวอักษรที่พิมพ์เดินทางในอุโมงค์ WireGuard ของ Tailscale เข้า Node บนเครื่องคุณ แล้วลงไปที่ PTY ตัวจริง

PTY อยู่ฝั่ง Mac ทั้งหมด มือถือจึงเป็นแค่จอกับคีย์บอร์ด — นั่นคือเหตุผลที่จอดับแล้ว งานไม่หยุด และเป็นเหตุผลเดียวกับที่ประวัติย้อนหลังกลับมาครบเมื่อเปิดใหม่
03 — พาชมของจริง

ทุกอย่างที่เคยต้องเดินไปหน้าเครื่อง ถูกย้ายมาไว้ในมือ

ภาพทั้งหมดถ่ายจาก Orbit ที่รันอยู่จริง ไม่ใช่ mockup — สคริปต์เดินแอปทีละหน้าจอ แล้วบันทึกภาพเอง เพื่อให้คู่มือไม่แก่กว่าโค้ด

Terminal

agent ตอบคุณบนจอ 6 นิ้ว โดยไม่ต้องย่ออะไรเลย

Claude Code, Codex หรือ Gemini รันในเทอร์มินัลจริง สีครบ กล่องคำถามครบ กด Enter ตอบได้ กด Ctrl+C หยุดได้ แถบปุ่มด้านล่างมีคีย์ที่คีย์บอร์ดมือถือไม่มี — Esc, Tab, Ctrl, ลูกศร และ ^C

พิมพ์ · พูด · แนบรูป

พิมพ์ยาว ๆ บนจอสัมผัสไม่สนุก จึงมีอีกสองทาง

ปุ่มปากกาเปิดกล่องข้อความที่แก้ได้ก่อนส่ง ปุ่มไมค์เปิด dictation ไทย/อังกฤษ ที่ถอดเสียงมาให้แก้ก่อนเช่นกัน — เพราะเครื่องถอดเสียงฟังผิดได้ และที่ที่ควรแก้คำผิดคือก่อนกดส่ง ไม่ใช่ในพรอมป์ตของ agent

รูปจากกล้องหรืออัลบั้มอัปโหลดขึ้น Mac แล้ววาง path ลงเทอร์มินัลให้เอง
Changes

เทอร์มินัลบอกว่า agent ทำอะไร แท็บนี้บอกว่ามันเขียนอะไร

สถานะ git ของโฟลเดอร์ที่ session นั้นอยู่ — ไฟล์ที่แก้ จำนวนบรรทัดเข้าออก และไฟล์ที่ยังไม่เคยถูก track เปิดดูดิฟฟ์ทีละ hunk ได้ stage ได้ commit ได้ โดยไม่ต้องพิมพ์คำสั่ง git บนจอสัมผัส

Preview

ดูงานที่เพิ่งแก้ ทั้งแบบภาพนิ่งและแบบกดได้จริง

Orbit หา dev server ที่รันอยู่บนเครื่องเอง แล้วให้เลือกสองอย่าง: capture เป็นภาพ (เรนเดอร์ด้วย Chrome จริงที่ขนาดจอมือถือ แท็บเล็ต หรือเดสก์ท็อป) หรือเผยแพร่พอร์ตนั้น เข้า tailnet แล้วเปิดเป็นเฟรมทับเทอร์มินัล — แตะได้ กรอกฟอร์มได้ โดย session ไม่หลุด

Sessions

หลาย session พร้อมกัน และรู้ว่าอันไหนกำลังรอคุณ

แถวที่มีชีวิตเรืองแสงจากข้างใน แถวที่รอคำตอบมีขอบสว่าง — สองอย่างนี้อยู่คนละช่อง ของสายตา จึงไม่กลืนกัน session ที่จบแล้วเปิดย้อนดูได้แบบอ่านอย่างเดียว และกด Resume ให้ agent คุยต่อจากบทสนทนาเดิมได้

การอนุมัติ

คำสั่งที่ทำลายของได้ ต้องผ่านนิ้วคุณก่อน

ทุกก้อนข้อความที่ถูกวาง พูด หรือส่งมาจากอัตโนมัติ ถูกกรองที่ฝั่งเซิร์ฟเวอร์ด้วยชุด pattern เดียวกับที่ใช้กรองคำสั่งของ agent — ลบทั้งโฟลเดอร์, ยกสิทธิ์เป็น root, force push, เขียนดิสก์ดิบ, fork bomb เจอแล้วหยุดค้างไว้ พร้อมแสดงคำสั่งเต็ม ๆ

ตัวเลือกแรกคือตัวเลือกที่ปลอดภัยเสมอ และไม่มีใครตอบ = ปฏิเสธ
เริ่ม session

เลือก agent เลือกโฟลเดอร์ แล้วเริ่ม

agent ที่ติดตั้งไว้จริงบนเครื่องเท่านั้นที่กดได้ — ตัวที่ยังไม่มีจะบอกตรง ๆ ว่า not installed ตัวเลือกโฟลเดอร์จำที่ที่คุณเพิ่งทำงานไว้ให้ ทำเครื่องหมาย repo ที่เป็น git และเตือนเมื่อคุณกำลังจะปล่อย agent ลงในโฟลเดอร์ที่กว้างเกินไป

04 — ฝั่ง agent

ให้ agent มองเห็นงานตัวเอง และเรียกหาคุณเป็น

ที่ผ่านมาคือมือถือสั่ง Mac ส่วนนี้คือทางกลับกัน — MCP server ที่มากับ Orbit ทำให้ agent ที่รันอยู่ใน session เห็นภาพงานของตัวเอง และส่งเสียงถึงคนถือมือถือได้

orbit_capture

เรนเดอร์เว็บที่รันอยู่แล้วส่งภาพกลับให้ agent เห็นเอง ไม่ใช่ path

orbit_screen

จับหน้าจอ Mac จริง — Simulator, Xcode, แอป native ที่ headless Chrome มองไม่เห็น

orbit_preview

เปิดแอปที่รันอยู่จริงบนมือถือ ตรงหน้าที่ agent ระบุ แตะกดได้จริง

orbit_notify

ส่งข้อความสั้นขึ้นมือถือ — "เสร็จแล้ว" หรือ "กำลังรอคุณอยู่"

orbit_ask

ถามคำถามขึ้นมือถือแล้วรอ จนกว่าจะมีคนกดตอบ

รู้ว่า agent กำลังรอคุณอยู่

กล่องคำถามของ Claude Code วาดอยู่ใน terminal เท่านั้น — จากมือถือที่คว่ำอยู่บนโต๊ะ มันหน้าตาเหมือน session ที่กำลังคิด และรอได้ทั้งคืน hook ส่งจังหวะพวกนั้นมาที่ Orbit

ปลุกมือถือที่หลับอยู่

iOS หยุดหน้าเว็บและตัดซ็อกเก็ตเมื่อล็อกจอ ข้อความที่ส่งตอนนั้นจึงไม่ถึงใคร Orbit เก็บไว้ส่งซ้ำให้เครื่องที่ต่อเข้ามาทีหลัง และมี Web Push ปลุกตอนแอปปิดสนิท

เงียบเมื่อคุณเห็นอยู่แล้ว

ทุกข้อความจาก hook ส่งแบบ quiet — เปิด Orbit ดูอยู่จะไม่เด้งอะไรเลย จะแจ้งก็ต่อเมื่อคุณไม่ได้ดู

05 — ความปลอดภัย

มันคุมคอมพิวเตอร์ส่วนตัวคุณ จึงต้องคิดเรื่องนี้ก่อน

Token ที่ไม่เคยโผล่ใน URL

access token ถูกสร้างลง ~/.orbit/config.json และส่งเป็น Authorization header เท่านั้น — ไม่เคยอยู่ใน URL ที่จะไปโผล่ใน log ของ proxy หรือประวัติเบราว์เซอร์ ซ็อกเก็ตกับ <img> ซึ่งพก header ไม่ได้ ใช้คุกกี้ HttpOnly ที่เก็บ hash ของ token และอนุญาตเฉพาะการอ่าน

สองด่าน สองแหล่งที่มา

คำสั่งที่ คุณ วางลงเทอร์มินัลถูกกรองที่เซิร์ฟเวอร์ ส่วนคำสั่งที่ agent รันเองผ่าน Bash tool ถูกกรองด้วย hook ตัวที่สอง ด้วย pattern ชุดเดียวกัน — เพราะสองทางนี้ไม่ได้ผ่านโค้ดเส้นเดียวกัน

ไม่มีอะไรโผล่สู่อินเทอร์เน็ต

Tailscale สร้างเครือข่ายส่วนตัวระหว่างอุปกรณ์ของคุณเอง ไม่ต้องเปิดพอร์ตที่เราเตอร์ ไม่ต้องทำ DDNS และไม่มีที่อยู่สาธารณะให้ใครสแกนเจอ

ขอบเขตที่บังคับไว้ในโค้ด

session เริ่มได้เฉพาะในโฟลเดอร์ใต้ home ของคุณ การเผยแพร่พอร์ตต้องมีอะไรตอบ HTTP บนพอร์ตนั้นอยู่ก่อน และ path ที่ agent ส่งมาต้องเป็น path บนโฮสต์ของเราเอง

06 — เริ่มใช้

จากศูนย์ถึงสั่งงานจากมือถือ

ทุก path ถูกหาจากตำแหน่งของ checkout เอง ไม่มีอะไรให้แทนที่ด้วยมือ และรันซ้ำได้เสมอโดยไม่เกิดของซ้อน 

# หนึ่งครั้งต่อเครื่อง
git clone <repo> orbit && cd orbit
make install
make setup        # build + ลงทะเบียน MCP + ติดตั้ง hook

# เปิดใช้งาน
make phone        # :3001 + Tailscale HTTPS แล้วเปิดลิงก์บนมือถือ
make stop         # เลิกงาน

ต้องมีอะไรบ้าง

macOS, Node 20+, Claude Code บน PATH, Google Chrome สำหรับ capture และ Tailscale เมื่ออยากใช้จากนอกบ้าน

ครั้งแรกจะเจออะไร

คอนโซลพิมพ์ access token ออกมา — เอาไปกรอกในหน้า login บนมือถือ ลบ ~/.orbit/config.json เมื่ออยากเปลี่ยน token ใหม่
