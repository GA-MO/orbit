01 — Orbit คืออะไร

ไม่ใช่แอปแชทที่คุยกับ AI แต่คือรีโมทของเครื่องคุณเอง

สิ่งที่คุณเห็นบนมือถือคือ terminal จริงตัวเดียวกับที่รันอยู่บน Mac — ANSI สี, TUI, prompt ที่ต้องกดตอบ, Ctrl+C, scrollback ครบ ไม่มีการแปลงเป็นข้อความสวย ๆ ระหว่างทาง

MacBook คือ source of truth

ไฟล์ กิต เครื่องมือ และ agent ทั้งหมดอยู่บนเครื่องคุณ Orbit ไม่ซิงก์โค้ดขึ้นที่ไหน และไม่มีบัญชีให้สมัคร — single-user, local-first

Session ไม่ตายเมื่อจอดับ

PTY อยู่ฝั่ง Mac มือถือเป็นแค่จอ ปิดเบราว์เซอร์ สลับแอป เน็ตหลุด กลับมาแล้วงานยังเดินอยู่ พร้อมประวัติที่เล่นย้อนกลับให้ครบ

มือถือเห็น ก็สั่งได้

พิมพ์ พูด ส่งรูป หรือกด capture หน้าเว็บที่ agent เพิ่งแก้ — ทุกอย่างจบในจอเดียวโดยไม่ต้องเดินไปเปิดฝาโน้ตบุ๊ก

เส้นแบ่งที่ชัดเจน: Orbit ไม่ได้แทน agent และไม่ได้เขียนโค้ดเอง — มันคือชั้นที่ทำให้ agent ซึ่งออกแบบมาสำหรับหน้าจอ 27 นิ้ว ใช้งานได้จริงบนจอ 6 นิ้วในมือคุณ

03 — Flow การทำงาน

เดินทีละก้าว ดูว่าข้อมูลวิ่งผ่านอะไรบ้าง

เลือกสถานการณ์ แล้วกด Play — กล่องที่กำลังทำงานจะสว่างขึ้นตามจังหวะ หรือแตะขั้นตอนไหนก็ได้เพื่อกระโดดไปตรงนั้น

04 — ความสามารถ

ทุกอย่างที่ต้องเดินไปหน้าเครื่อง ถูกย้ายมาไว้ในมือ

Terminal

Terminal ตัวจริง

xterm.js ↔ WebSocket ↔ node-pty ↔ zsh — สี ANSI, cursor movement, prompt แบบโต้ตอบ, Ctrl+C, resize ตามคีย์บอร์ดบนจอ และแถบคีย์ลัด สำหรับปุ่มที่คีย์บอร์ดมือถือไม่มี

สลับ agent ได้ในแตะเดียว

Claude Code, Codex CLI, Gemini CLI หรือ shell เปล่า ๆ — Orbit ตรวจเองว่าเครื่องคุณลงตัวไหนไว้บ้าง ผ่าน login shell จริง การ์ดของตัวที่ยังไม่ได้ลงจะจางไว้

Session ที่จำได้ข้ามการรีสตาร์ท

metadata + ประวัติ terminal เก็บใน ~/.orbit/ server ดับแล้วเปิดใหม่ session เก่ายังเปิดอ่านได้แบบ read-only และกด ↻ ให้ agent สานบทสนทนาเดิมต่อได้

🎙 HTTPS เท่านั้น

สั่งงานด้วยเสียง ไทย/EN

พูดแล้วได้ transcript ที่ แก้ก่อนส่งได้ — Insert (พิมพ์เฉย ๆ) หรือ Send (พิมพ์แล้วเคาะ Enter) จูนมาสำหรับ WebKit บน iPhone โดยเฉพาะ

คัดลอกได้ แตะลิงก์ได้

กดค้างเพื่อเลือก คำ ใต้นิ้ว (path ยาว ๆ ติดมาทั้งก้อน) ลากจุดสองข้างปรับทีละตัวอักษร หรือกด Line เอาทั้งบรรทัด แล้ว Copy — ส่วน URL แตะแล้วเลือกได้ว่าจะเปิดหรือคัดลอก (ไม่เด้งออกจากแอปเอง) localhost ถูกแปลงให้ชี้กลับมาที่ Mac ให้อัตโนมัติ

ส่งภาพให้ agent

เลือกรูปหรือถ่ายสด → อัปโหลดไป ~/.orbit/uploads/ แล้ว path ถูกพิมพ์ลง terminal ให้อัตโนมัติ พิมพ์ต่อได้เลยว่าจะให้ทำอะไรกับภาพนั้น

ตรวจงานด้วยตา

ใส่ URL ของ dev server แล้วกด Capture — Chrome จริงบน Mac render ที่ viewport Phone / Tablet / Desktop หรือจับหน้าจอ Mac ทั้งจอ สำหรับ Simulator กับแอป native

Guard

ด่านกรองคำสั่งอันตราย

ข้อความที่วางหรือสั่งด้วยเสียงถูกตรวจก่อนถึง shell — เจอ rm -rf, sudo, force push ฯลฯ จะยึดไว้แล้วถามยืนยันพร้อมแสดงคำสั่งเต็ม

ติดตั้งเป็นแอป (PWA)

manifest + service worker + ไอคอน — Add to Home Screen แล้วเปิดเต็มจอ ไม่มีแถบเบราว์เซอร์ ฟอนต์ bundle มาในเครื่อง ไม่แตะ CDN

MCP

agent เรียกหาคุณได้เอง

MCP server ที่มากับ Orbit ให้ agent capture เอง ดูภาพเอง เตือนขึ้นมือถือ และ ถามแล้วรอ คำตอบจากคุณกลางทาง

05 — คู่มือใช้งาน

เดินครบทุกหน้าจอ ด้วยภาพจากเครื่องจริง

ทุกภาพถ่ายจากการใช้งานจริงบน viewport ขนาด iPhone (390×844) — แตะหัวข้อเพื่อกางรายละเอียด ภาพทางซ้ายจะเปลี่ยนตาม

หน้า login — ใส่ access token ครั้งเดียว
01จับคู่กับ Mac ครั้งแรก

รัน server บน Mac แล้วเปิด URL จากมือถือ ครั้งแรกจะเจอหน้า login ใส่ access token ที่ server พิมพ์ใน console ([orbit] access token: …) ใส่ครั้งเดียว เครื่องจำไว้ให้

  • HTTPS ผ่าน Tailscale (แนะนำ) — https://<เครื่อง>.<tailnet>.ts.net ใช้ได้ทุกฟีเจอร์ และเข้าจากนอกบ้านได้
  • LAN ธรรมดา — http://<ip-ของ-mac>:7788 ต้องอยู่ WiFi วงเดียวกัน และเสียงกับ Add to Home Screen จะใช้ไม่ได้
ที่เสียงใช้ไม่ได้บน HTTP ไม่ใช่ข้อจำกัดของ Orbit — เบราว์เซอร์ยอมให้ขอไมค์และลงทะเบียน service worker เฉพาะบน secure context เท่านั้น
02แท็บ Terminal: shell จริงบนมือถือ

เข้ามาแล้วเจอ terminal ที่ต่อกับ zsh บน Mac ตรง ๆ header บอกว่ากำลังอยู่ session ไหน โฟลเดอร์อะไร และสถานะเชื่อมต่อ — วงแหวน orbit หมุนคือต่ออยู่

ในภาพ: สร้างโปรเจกต์ orbit-demo เขียน index.html แล้วรัน python3 -m http.server 4321 ทั้งหมดพิมพ์จากมือถือ

Session ไม่ตายเมื่อจอดับ — ปิดเบราว์เซอร์ สลับแอป หรือเน็ตหลุด กลับมาแล้ว shell ยังรันต่ออยู่พร้อมประวัติครบ
03แท็บ Sessions: ศูนย์ควบคุม

เห็นทุก session ในที่เดียว จุดสีเหลืองกระพริบคือกำลังรันอยู่ แต่ละแถวบอก agent โฟลเดอร์ และอายุ

  • แตะแถว — สลับไป session นั้น
  • ✎ — ตั้งชื่อ/เปลี่ยนชื่อ
  • 🗑 ตัวที่รันอยู่ — หยุด ประวัติย้ายไปหมวด Ended
  • ＋ ตัวที่จบแล้ว — เริ่มใหม่ด้วย agent + โฟลเดอร์ + ชื่อเดิม
  • 🗑 ตัวที่จบแล้ว — ลบถาวรพร้อมประวัติ

ไม่ตั้งชื่อก็ยังแยกออก — คำสั่งแรกที่พิมพ์จะกลายเป็นชื่อให้เอง (shell ใช้คำสั่ง, agent ใช้พรอมป์ตแรก) ขึ้นเป็น monospace ให้รู้ว่าไม่ใช่ชื่อที่ตั้งเอง

04สร้าง session ใหม่
  • เลือก agent — การ์ดจะจางถ้ายังไม่ได้ติดตั้ง CLI ตัวนั้น
  • ตั้งชื่อ ไม่บังคับ แต่ช่วยมากเมื่อเปิดหลายตัวพร้อมกัน
  • เลือกโฟลเดอร์ — recent projects กดแตะเดียว หรือ browse เอง; git repo มีสัญลักษณ์ branch สีเขียว และมีช่อง filter เมื่อโฟลเดอร์เยอะ
เผลอเลือกโฟลเดอร์กว้าง ๆ อย่าง home จะมีคำเตือนสีเหลืองขึ้น — เตือนแต่ไม่ห้าม
05ใช้ Claude Code จากมือถือ

เลือกการ์ด Claude Code + โฟลเดอร์โปรเจกต์ → ได้ Claude Code ตัวจริงรันบน Mac สลับโมเดลด้วย /model haiku ใช้ slash command ได้ครบเหมือนนั่งหน้าเครื่อง

agent ถูก launch ผ่าน zsh -lic 'exec <cmd>' เพื่อให้ PATH จริงของคุณมีผล — ออกจาก agent เมื่อไหร่ session ก็จบตามนั้น

06สั่งงานด้วยเสียง

ปุ่มไมค์บน header → พูด → transcript ขึ้นสด แก้ข้อความได้ก่อนส่ง แล้วเลือก Insert หรือ Send ⏎

บน iPhone ต้องรู้ — iOS ไม่ได้ถอดเสียงในเครื่อง แต่ยิงไปที่บริการ dictation ของ Apple จึงมีข้อจำกัดที่ Android ไม่มี
  • เลือกภาษาก่อนพูด — ปุ่ม ไทย/EN ฟังทีละภาษา ไทยปนอังกฤษในประโยคเดียวไม่เวิร์ค ศัพท์เทคนิคอย่าง npm run build ให้พิมพ์เอาเองในช่อง transcript
  • ฟังทีละช่วง — เงียบสักพัก iOS ปิด session เอง กด Continue listening พูดต่อได้ ข้อความเดิมไม่หาย
  • สวิตช์ 3 ตัวต้องเปิดครบ — Speech Recognition ให้ Safari, Enable Dictation, และ Microphone ใน Website Settings; ปิดตัวไหนก็ขึ้น service-not-allowed เหมือนกันหมด แก้แล้วต้อง reload
  • ห้ามใช้จากไอคอน Home Screen — WebKit บล็อก speech recognition ใน PWA แบบ standalone ให้เปิดผ่าน Safari ปกติ
07แท็บ Captures: ตรวจงานด้วยตา

ใส่ URL ของ dev server เลือกขนาดจอ (Phone / Tablet / Desktop หรือติ๊ก Full page) แล้วกด Capture — Mac เปิด Chrome แบบ headless render แล้วเก็บภาพไว้ในแกลเลอรี

  • dev server ไม่ได้รัน → ขึ้น error ตรง ๆ ไม่ใช่เก็บภาพหน้า "เข้าไม่ได้" ของ Chrome มาให้เหมือนสำเร็จ
  • URL ที่ capture สำเร็จกลายเป็นปุ่มลัด (เก็บ 4 อันล่าสุด) ไม่ต้องพิมพ์ localhost:5173 ใหม่บนคีย์บอร์ดมือถือ
  • ใต้ภาพบอกว่าเป็นภาพของอะไร ไม่ใช่มีแค่เวลา

อยากกดจริงไม่ใช่ดูภาพนิ่ง — ปุ่ม เปิดในเบราว์เซอร์ ข้างปุ่ม Capture เปิดแอปที่รันบน Mac เป็นแท็บจริงบนมือถือ และ npm run preview:on เติม HTTPS ให้ dev server ที่ :8443 สำหรับแอปที่ต้องการ secure context ของตัวเอง

08ส่งภาพกลับให้ agent ดูต่อ

แตะภาพเพื่อดูเต็มจอ กด ⇥ เพื่อแทรก path ของภาพลง terminal — แล้วพิมพ์ต่อว่า "ทำไมปุ่มเบี้ยว ดูจากภาพนี้"

สลับสวิตช์ Mac screen แล้ว Capture = จับหน้าจอ Mac ทั้งจอ ใช้ดูของที่ headless Chrome เห็นไม่ได้ — iOS Simulator, Xcode, แอป native, Figma

ถ้ายังไม่ได้เปิดสิทธิ์ Screen Recording ให้แอปที่รัน Orbit server macOS จะไม่ error แต่จะได้ภาพ desktop เปล่าที่ไม่มีหน้าต่างแอปเลย — เห็นแบบนั้นเมื่อไหร่ให้ไปเปิดสิทธิ์ที่ Privacy & Security
09เมื่อเจอคำสั่งอันตราย

Input ที่มาเป็นก้อน (วางข้อความ, สั่งด้วยเสียง, automation) ถูกตรวจกับ pattern อันตราย เจอแล้วคำสั่งจะถูกยึดไว้ก่อน และถามยืนยันพร้อมแสดงคำสั่งเต็มให้อ่าน

Deny = ทิ้งคำสั่ง ไม่มีอะไรถึง shell · Run anyway = ปล่อยผ่าน

การพิมพ์สดทีละตัวอักษรไม่ถูกตรวจ — มันประกอบกลับเป็นคำสั่งอย่างเชื่อถือได้ไม่ได้ และนั่นคือมือคุณเองอยู่แล้ว
10ประวัติไม่หาย และทำงานต่อได้

Session ที่จบแล้ว (agent ออกเอง, กดหยุด, หรือ server restart) ยังเปิดดูได้ — terminal แสดงประวัติทั้งหมดแบบ read-only พร้อมป้ายใน header แถบคีย์ลัดซ่อนไปเองเพราะไม่มี PTY ให้ส่งอะไรแล้ว

  • ↻ Resume — ให้ agent สานบทสนทนาล่าสุดของโฟลเดอร์นั้นต่อ (claude --continue, codex resume --last)
  • ＋ New — เริ่มใหม่หมดด้วย agent + โฟลเดอร์ + ชื่อเดิม ไม่เอาบทสนทนาเก่ามา
↻ ขึ้นเฉพาะ session ที่จบล่าสุดของโฟลเดอร์+agent นั้น และต้องไม่มีตัวไหนรันค้างอยู่ — เพราะคำสั่งพวกนี้รู้จักแค่ "โฟลเดอร์" ไม่รู้จัก session ของ Orbit กดจากรายการเก่าก็จะได้บทสนทนาล่าสุดอยู่ดี และถ้ามี agent ทำงานอยู่ จะกลายเป็นสองตัวจับบทสนทนาเดียวกัน

06 — ความปลอดภัย

มันคุมคอมพิวเตอร์ส่วนตัวคุณ จึงต้องคิดเรื่องนี้ก่อน

ลองพิมพ์คำสั่งดูว่าด่านกรองจะจับหรือไม่ — ตัวตรวจด้านล่างใช้ชุด pattern ชุดเดียวกับที่อยู่ใน server/src/approval.ts จริง

Command screening · ลองเอง

Token ที่ไม่เคยโผล่ใน URL

ทุก /api/* และ WebSocket ต้องมี Authorization: Bearer token ถูกสร้างลง ~/.orbit/config.json และพิมพ์ใน console ครั้งแรก

แต่ WebSocket handshake กับ <img src> แนบ header ไม่ได้ — สองอย่างนี้จึงใช้คุกกี้ HttpOnly; SameSite=Strict ที่ออกโดย GET /api/auth/check ซึ่งเก็บ แฮชของ token ไม่ใช่ตัว token และอนุญาตแค่การอ่านกับ socket ไม่เคยอนุญาตให้เขียน

สองด่าน สองแหล่งที่มา

ด่านแรกดูสิ่งที่ คุณ ส่งเข้า terminal ด่านที่สองคือ hook orbit-approve.mjs ที่ดักเครื่องมือ Bash ของ agent เอง ซึ่งไม่เคยผ่าน PTY เลย

ไม่มีใครตอบ หรือไม่มีมือถือต่ออยู่ → ปฏิเสธ (fail closed) · Orbit server ไม่ได้รัน → ปล่อยผ่าน (fail open) เพื่อไม่ให้ Claude Code พังตอนใช้งานปกติ

ไม่มีอะไรโผล่สู่อินเทอร์เน็ต

Tailscale สร้าง tunnel WireGuard ระหว่างอุปกรณ์ของคุณเอง — ไม่ต้องเปิดพอร์ต ไม่ต้องตั้ง DDNS tailscale serve เติม HTTPS ใบจริงให้โดยยังอยู่ใน tailnet เท่านั้น

ขอบเขตที่บังคับไว้ในโค้ด

การเลือกโฟลเดอร์ถูกจำกัดไว้ใต้ home directory (safePath()) อัปโหลดมีเพดานขนาด และ session id ที่มือถือจำไว้แต่ Mac ไม่มีแล้ว จะถูกตอบว่า gone แทนที่จะแอบเปิด shell ใหม่ในโฮมใต้ id เดิม

07 — ฝั่งของ agent

ให้ agent มองเห็นงานตัวเอง และเรียกหาคุณเป็น

ปกติ Orbit คือมือถือสั่ง Mac — MCP server ที่มากับโปรเจกต์คือทางกลับกัน ทั้งหมดคุยกับ server ที่พอร์ต 7788 ด้วย token ใน ~/.orbit/config.json

orbit_capture

render เว็บที่รันอยู่แล้ว เห็นภาพเลย ไม่ใช่ได้แค่ path — รูปโผล่ในแท็บ Captures ของคุณด้วย

orbit_screen

จับหน้าจอ Mac จริง สำหรับ Simulator, Xcode, แอป native ที่ headless Chrome เห็นไม่ได้

orbit_notify

ส่งข้อความสั้นขึ้นมือถือ เช่น "งานเสร็จแล้ว" — เงียบไว้ถ้าคุณเปิด Orbit ดูอยู่

orbit_ask

ถามคำถามขึ้นมือถือ แล้วรอ จนกว่าจะกดตอบ หมดเวลา 120 วิ ก็บอก agent ว่าไม่มีใครตอบ

รู้ว่า Claude กำลังรอคุณอยู่

กล่องคำถามและการขออนุญาตของ Claude Code วาดอยู่ใน terminal เท่านั้น — จากมือถือที่คว่ำอยู่บนโต๊ะ มันหน้าตาเหมือน session ที่กำลังคิด และรอได้ทั้งคืน

hook orbit-notify-hook.mjs ส่งจังหวะพวกนั้นมาที่ Orbit: AskUserQuestion พร้อมตัวเลือก, Notification ที่แปลว่ากำลังรอ, และ Stop เฉพาะ session ที่เปิดจาก Orbit — ทั้งหมดส่งแบบ quiet จึงไม่เด้งซ้ำสิ่งที่คุณเห็นอยู่แล้ว

ปลุกมือถือที่หลับอยู่

iOS แช่แข็งหน้าเว็บและตัด socket ตอนล็อกจอ ข้อความที่ส่งตอนนั้นจึงไม่ถึงใครเลย Orbit อุดช่องนี้สองชั้น: เก็บข้อความไว้ replay ให้คนที่ต่อเข้ามาคนถัดไป (ครั้งเดียว และเฉพาะที่ยังไม่เคยส่งถึงใคร) กับ Web Push ที่ปลุก service worker ได้แม้แอปปิดสนิท

push ยิงเฉพาะตอนช่องทางสดหาใครไม่เจอ — แอปที่เปิดอยู่จึงไม่ได้ทั้ง banner และ toast พร้อมกัน

ก่อนสั่ง orbit_screen: เมื่อสิทธิ์ผ่านแล้ว มันเห็นทุกอย่างบนจอ — ตอนทดสอบครั้งแรก ภาพที่ได้มี terminal ที่มี access token ของ Orbit พิมพ์ค้างอยู่ติดมาด้วย และภาพนั้นเข้าไปอยู่ในบริบทของ agent ปิดหรือย่อสิ่งที่ไม่อยากให้เห็นก่อน
08 — เริ่มใช้งาน

จากศูนย์ถึงสั่งงานจากมือถือ

ทั้งหมดรันบน Mac ของคุณ ไม่ต้องสมัครอะไร

ต้องมีอะไรบ้าง

macOS (Apple Silicon), Node.js, zsh และ agent CLI อย่างน้อยหนึ่งตัว — Google Chrome สำหรับฟีเจอร์ capture (ใช้ Chrome ของระบบ ไม่ดาวน์โหลด browser เพิ่ม)

เกร็ดที่ทำให้ไม่ต้องงง

npm ถอด execute bit ของ spawn-helper ที่มากับ node-pty ทำให้ PTY spawn ไม่ขึ้น — postinstall ที่ root แก้สิทธิ์ให้อัตโนมัติทุกครั้งที่ install

อยากหมุน token ใหม่

ลบ ~/.orbit/config.json แล้วรัน server ใหม่ — จะได้ token ใหม่พิมพ์ใน console และเครื่องที่เคย login ไว้จะเด้งกลับหน้า login

10 — สถานะโปรเจกต์

ทุกเฟสในสเปกถูกทำครบแล้ว

และมีของที่เกินสเปกเดิมมาอีกชุดหนึ่ง

Phase 1
Terminal ตัวจริง

xterm.js + node-pty + WebSocket, persistent session, auto-reconnect, เลย์เอาต์สำหรับมือถือ

Phase 2
Agent provider system

Claude Code / Codex / Gemini / shell พร้อมตรวจว่าติดตั้งตัวไหนไว้ และ folder picker ที่รู้จัก git repo

Phase 3
Session management

metadata + ประวัติลง ~/.orbit/, อยู่รอดข้าม server restart, resume บทสนทนาเดิมได้

Phase 4
เสียง ภาพ auth และ PWA

voice input ไทย/EN, image upload, access token + session cookie, ติดตั้งลงหน้าจอโฮมได้

Phase 5
Screenshot validation + command approval

capture ผ่าน Chrome จริง, Mac screen, และด่านกรองคำสั่งอันตราย

Phase 6
Mobile UX polish

named session, ชื่ออัตโนมัติจากคำสั่งแรก, แถบคีย์ลัด, safe area และคีย์บอร์ดบนจอ

Phase 7
ฝั่งของ agent

MCP server, ช่องทาง Mac→มือถือ, Web Push, hook แจ้งเตือนและ hook อนุมัติ
