01 — What Orbit is

Not a chat app for talking to an AI. A remote for your own machine.

What you see on the phone is the same terminal running on the Mac — ANSI color, TUIs, prompts that need an answer, Ctrl+C, full scrollback. Nothing is reformatted into pretty text along the way.

01

The MacBook is the source of truth

Files, git, tools and every agent live on your machine. Orbit does not sync code anywhere, and there is no account to sign up for — single-user, local-first.

02

Sessions survive the screen going dark

The PTY lives on the Mac; the phone is only a screen. Close the browser, switch apps, lose the connection. Come back and the work is still running, with the full history replayed.

03

If the phone can see it, it can drive it

Type, speak, attach an image, review the diff, open the app that is actually running — all on one screen, without walking over to open the laptop lid.

A clear line: Orbit does not replace the agent and does not write code itself — it is the layer that makes an agent designed for a 27-inch screen usable on the 6-inch one in your hand.
02 — The path of one keystroke

From your finger to zsh, through five layers

There is no cloud on this path. Each character you type travels through Tailscale's WireGuard tunnel into Node on your own machine, then down to a real PTY.

Phonexterm.js in Safari, or the PWA on your home screen
tailnetHTTPS 443 via tailscale serve, without touching the router
OrbitBun on :7788 — auth, WebSocket, REST
node-ptyA real terminal, sized to match the phone's screen
zsh + agentYour own PATH, in your own folder
The PTY lives entirely on the Mac, so the phone is only a screen and a keyboard. That is why work keeps going when the display sleeps, and why the full scrollback comes back when you reopen the app.
03 — The tour

Everything that used to mean walking to the machine now sits in your hand

Every image is captured from a running Orbit, not a mockup. A script walks the app screen by screen and takes the shots itself, so the guide never falls behind the code.

Terminal

The agent answers you on a 6-inch screen, with nothing cut down

Claude Code, Codex or Gemini runs in a real terminal, with full color and every prompt box intact. Press Enter to answer, press Ctrl+C to stop. The key bar at the bottom carries the keys a phone keyboard lacks — Esc, Tab, Ctrl, the arrows and ^C.

Type · Speak · Attach

Long typing on a touchscreen is no fun, so there are two other ways

The pen button opens a text box you can edit before sending. The mic button opens Thai/English dictation that also hands you the transcript to edit first — because speech recognition mishears, and the place to fix a wrong word is before you send it, not inside the agent's prompt.

Photos from the camera or your library upload to the Mac, and the path is pasted into the terminal for you
Changes

The terminal tells you what the agent did. This tab tells you what it wrote

The git status of the folder that session lives in — modified files, lines added and removed, and files not yet tracked. Open the diff hunk by hunk, stage, and commit, without typing a single git command on a touchscreen.

Preview

See what you just changed, as a still image or as a page you can actually tap

Orbit finds the dev servers running on the machine and offers two options: capture an image (rendered by real Chrome at phone, tablet or desktop size), or publish that port to the tailnet and open it as a frame over the terminal — tap it, fill in forms, and the session stays put.

Sessions

Several sessions at once, and you know which one is waiting on you

A live row glows from within. A row waiting for an answer has a bright edge. The two signals sit in different channels of your eye, so they never blur together. An ended session opens read-only, and Resume lets the agent pick up the earlier conversation where it left off.

Approvals

A command that can destroy things goes through your finger first

Every block of text that is pasted, spoken or sent by automation is screened server-side with the same set of patterns used to screen the agent's own commands — deleting a whole folder, escalating to root, force push, raw disk writes, fork bombs. A match holds the command and shows it to you in full.

The first option is always the safe one, and no answer means no.
Start a session

Pick an agent, pick a folder, and go

Only agents actually installed on the machine can be selected — the ones that are missing say not installed, plainly. The folder picker remembers where you last worked, marks the repos that are git, and warns you when you are about to drop an agent into a folder that is too broad.

04 — The agent side

Let the agent see its own work, and reach you

So far it has been the phone driving the Mac. This is the other direction. The MCP server that ships with Orbit lets the agent running in a session see its own work, and speak to whoever is holding the phone.

orbit_capture

Renders the web app that is already running and hands the image back to the agent. The image, not a path.

orbit_screen

Captures the real Mac screen. Simulator, Xcode, native apps that headless Chrome cannot see.

orbit_preview

Opens the actual running app on your phone, at the page the agent names. You can tap it for real.

orbit_notify

Sends a short message to your phone. "Done", or "Waiting on you."

orbit_ask

Puts a question on your phone and waits, until someone taps an answer.

Know when the agent is waiting on you

Claude Code draws its question box in the terminal, and nowhere else. From a phone lying face down on the desk, it looks like a session that is thinking, and it will wait all night. The hooks send those moments to Orbit.

Wake a sleeping phone

iOS suspends the page and drops the socket when the screen locks, so a message sent right then reaches no one. Orbit keeps it and re-sends it to the next device that connects, and Web Push wakes the phone when the app is fully closed.

Quiet when you are already looking

Every message from a hook is sent quiet. With Orbit open on screen, nothing pops up at all. It only notifies you when you are not looking.

05 — Security

It controls your personal computer, so this comes first

A token that never appears in a URL

The access token is generated into ~/.orbit/config.json and sent only as an Authorization header. It is never in a URL that would end up in a proxy log or browser history. The socket and <img>, which cannot carry a header, use an HttpOnly cookie that holds a hash of the token and permits reads only.

Two gates, two sources

Commands you paste into the terminal are screened at the server. Commands the agent runs itself through the Bash tool are screened by a second hook, with the same set of patterns. The two paths do not go through the same code.

Nothing exposed to the internet

Tailscale builds a private network between your own devices. No port to open on the router, no DDNS to set up, and no public address for anyone to find by scanning.

Boundaries enforced in code

A session can only start in a folder under your home. Publishing a port requires something already answering HTTP on that port. And a path the agent sends must be a path on our own host.

06 — Get started

From zero to driving it from your phone

One executable from a GitHub release, checksum verified before it installs. And orbit setup can be run again at any time without leaving duplicates behind. 

# Once per machine — one file, no runtime to install
curl -fsSL https://raw.githubusercontent.com/GA-MO/orbit/main/install.sh | bash
orbit doctor      # what this Mac has, and what it is missing
orbit setup       # register the MCP server + install the Claude Code hooks

# Turn it on
orbit phone       # run + Tailscale HTTPS, then open the link on your phone
orbit phone off   # close the front door

What you need

macOS (Apple silicon or Intel), Claude Code on PATH, Google Chrome for captures, and Tailscale when you want to use it away from home. No Node or Bun required.

What happens on first run

The console prints an access token. Enter it on the login page on your phone. Remove the token key in ~/.orbit/config.json when you want a new one.
